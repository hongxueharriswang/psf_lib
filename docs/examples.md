# Examples

Runnable scripts are in the [`examples/`](../examples/) directory.

1. **[Simulation Study](../examples/01_simulation_study.py)** — End-to-end validation on synthetic data.
2. **[Real Data Template](../examples/02_real_data_template.py)** — Template for institutional data.
3. **[Intent Recovery](../examples/03_intent_recovery.py)** — Validating Intent-to-Return inference.
4. **[Online Tracking](../examples/04_online_tracking.py)** — Real-time state estimation with particle filtering.
