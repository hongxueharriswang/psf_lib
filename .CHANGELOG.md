## [0.1.0] - 2025-01-15

### Added
- `PSFModel` class with six joint states (five persistence states + intent split).
- `baum_welch` for EM parameter estimation with structural constraints.
- `forward_backward` for state posteriors.
- `viterbi` for most-likely state sequences.
- `particle_filter` for online state estimation.
- `return_probabilities` and `withdrawal_probabilities` for horizon-specific predictions.
- `CompetingRiskSurvival` for discrete-time competing-risk models.
- `generate_operational_labels` for ground-truth label generation.
- Baseline models: `InactivityThresholdClassifier`, `LogisticDropoutModel`, `SurvivalWithoutIntent`.
- Evaluation: `evaluate_predictions`, `time_dependent_auc`, `concordance_index`, `compare_models`.
- `FeatureExtractor` for standard feature extraction.
- `simulate_cohort` for synthetic data generation.
- Comprehensive documentation and worked examples.
