# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 0.1.x   | ✅        |

## Reporting a Vulnerability

If you discover a security vulnerability, please email your.email@example.com
directly. Do not open a public issue.

We will:

1. Acknowledge receipt within 48 hours.
2. Investigate and confirm the issue.
3. Release a patch as soon as feasible.
4. Credit you in the release notes (unless you prefer anonymity).

## Scope

The PSF library processes de-identified educational data. Security concerns
include:

- Data leakage from model outputs.
- Re-identification from synthetic data.
- Injection vulnerabilities in data loaders.

We take these seriously and welcome reports.
